# تركيب إعادة تصميم إدارة المنصة — MIRSAD

## محتويات الحزمة

الحزمة تحتوي على الملفات الجديدة والمعدلة فقط، تحت المسار `frontend/`. لا تستبدل المشروع كاملاً.

## خطوات التركيب

1. أوقف خادم Vite الخاص بالواجهة الأمامية.
2. أنشئ نسخة احتياطية من مجلد `frontend/src/components` و`frontend/tests` إذا أردت الاحتفاظ بنسخة محلية إضافية.
3. فك ضغط `MIRSAD_enterprise_soc_admin_full_patch.zip` داخل المجلد الرئيسي للمشروع الذي يحتوي على مجلد `frontend`.
4. اسمح بدمج المجلدات واستبدال الملفات التي تحمل الأسماء نفسها.
5. من مجلد `frontend` نفّذ:

```powershell
npm ci
npm run build
npm run lint
node --test tests/admin-panel-architecture.test.mjs tests/admin-panel-sections.test.mjs tests/security-regression.test.mjs
```

6. بعد نجاح البناء، شغّل الواجهة بالطريقة المعتادة في مشروعك.
7. اختبر صفحة إدارة المنصة في اللغتين العربية والإنجليزية، وراجع الأقسام التسعة وتبديل المؤسسة في وضع Owner.

## الملفات التي لا تستبدلها أو تحذفها

- لا تستبدل أو تحذف ملفات `.env` أو `.env.*`.
- لا تغيّر `package.json` أو `package-lock.json` بسبب هذه الحزمة؛ لا توجد اعتماديات runtime جديدة.
- لا تغيّر قواعد البيانات أو ملفات Docker أو وحدات التخزين.

## ملاحظة التحقق

لم أتمكن من تنفيذ `npm ci` في بيئة إعداد الحزمة بسبب فشل DNS إلى `registry.npmjs.org` (`EAI_AGAIN`). لذلك لم يكتمل `npm run build` أو `npm run lint` هنا. اجعل نتائج الأوامر أعلاه شرطاً قبل اعتماد النسخة على جهازك.
